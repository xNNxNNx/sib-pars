# sib-pars

Программа для работы с данными о котировках криптовалют (coinmarketcap.com).

## Возможности

- Загрузка данных из CSV файла (currencies26.csv)
- Парсинг данных с сайта coinmarketcap.com (requests + BeautifulSoup)
- Просмотр всех загруженных криптовалют
- Поиск криптовалюты по названию

## Запуск

```
python main.py
```

## Зависимости

```
pip install requests beautifulsoup4
```
